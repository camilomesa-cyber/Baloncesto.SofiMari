# 🏀 La Técnica y las Lesiones en el Baloncesto

Sitio web educativo sobre las técnicas fundamentales del baloncesto y la prevención de lesiones deportivas.

## 📋 Contenido

- **Introducción** — Presentación del tema y objetivos
- **Técnicas Básicas** — Dribbling, pase, lanzamiento y defensa
- **Lesiones Más Comunes** — Tobillo, rodilla, musculares y dedos/manos
- **Metodología de Enseñanza** — Enfoque pedagógico progresivo
- **Prevención de Lesiones** — Consejos clave para cuidar el cuerpo

## 🚀 Cómo usar

1. Clona o descarga el repositorio
2. Abre `baloncesto.html` directamente en cualquier navegador web
3. No requiere servidor ni instalación — es un archivo HTML puro

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 con variables personalizadas y diseño responsive
- SVG ilustraciones originales
- Google Fonts (Bebas Neue + Nunito)

## ✨ Características

- Diseño responsive (adaptado para móvil y escritorio)
- Navegación fija con scroll suave
- Ilustraciones SVG propias para cada sección
- Paleta de colores naranja y oscuro estilo deportivo
